Backup: sign in with a GitHub token

Only needed if email sign-in isn't set up yet. The token stays in this browser.

How do I get a token? (one-time, 2 minutes)
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: FA Vision Admin. Expiration: 1 year.
  3. Repository access: Only select repositories → favisionenterprize.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token and copy it.
  6. For email sign-in (recommended): paste it once into Apps Script → Project Settings → Script properties as GITHUB_TOKEN. It then never needs to be on your phone.

Anyone with the token can change your website, so don't share it. If it leaks, delete it on GitHub and make a new one.
